# 领域文档

## 探索前读取

- 根目录 `GLOSSARY.md`。
- 如果存在 `GLOSSARY-MAP.md`，按其中的指引读取相关上下文的术语表。
- `docs/adr/` 中与当前工作相关的架构决策。

文档缺失时直接继续。`domain-modeling` 会在术语或决策确定后按需创建文档。

## 布局

本仓库使用单上下文布局：
- 术语表：根目录 `GLOSSARY.md`。
- 架构决策：`docs/adr/`。

## 使用术语

事项标题、重构建议、假设和测试名称采用术语表定义的词汇。
所需概念尚未收录时，判断它是否属于项目；确有缺口时记录供 `domain-modeling` 补充。

## 决策冲突

输出与已有 ADR 冲突时，明确指出 ADR 编号和重新讨论的理由。
