# 验收与一次修正

先核对原图保留项，再风格。程序报告仅证明输入与基准几何约束，不证明识别正确。

## 代码检查

- 分支有效，头数与填写的观察人数一致，物品/风景无人物。
- 无不支持的五官字段、原始 SVG 或额外颜色。
- 固定正脸基准、胶囊与中心距；背影/隐藏头无眼，侧脸最多一眼。
- 发块数、配件额度、头部最低尺寸、背景块数/对比、完整包围盒与白边。
- 纹理种子固定，稀疏边缘颗粒有上限。

通过时报告仍为 pending-source-review。

## 与实际原图比较

1. 主要主体数一致，删掉的确是无关内容。
2. 发型、配件、服装/物品结构可辨，没有新增道具或过度简化。
3. 头向、倾斜、姿态、相对位置与互动保留；侧脸未转正，背影仍背对。
4. 隐藏眼/耳仍隐藏，闭眼仍短弧；眼罩/墨镜不是额带，手/发遮挡位置正确。
5. 自由曲线未误作鼻嘴、眉毛、眼白、细发束，发型圆润。
6. 在 128px 缩略观看时大轮廓、胶囊、两色、留白仍清楚，配件未主导画面。
7. 地标与场景有原图依据，无新增人脸、文字、景物。

历史回归项：五条悟遮眼布不能上移补出双眼；索隆原图闭眼不能睁开。使用有原图对照的那张，不用角色知识替代观察。

## 重绘

几何错误按消息修改 JSON；语义或风格错误只改相关状态、曲线或层级。每输入最多两份候选：首次与一次修正。纯环境故障/命令拼写错误不算图像候选，不能因此反复修改视觉数据。

第二份仍不达标：标 failed，记录具体问题并说明未通过，保留材料；批量继续其它输入。不能把“导出文件”当“转换成功”。最终报告按如下字段更新，保留原哈希/版本/几何/路径：

```json
{
  "status":"passed",
  "semanticReview": {
    "status":"passed",
    "issues":[],
    "attempts":1,
    "note":"已与实际原图逐项比较，保留了闭眼与遮挡。"
  }
}
```

未查看原图不得写 passed。

## 版本验证

`npm test` 验证五分支、比例、隐藏/闭眼、色系、可重复 PNG、白边与不覆盖文件。合成样例不能证明真实发型拟合和互动质量。真人/动漫/物品已有用户历史对照可供后续选例，旅行与风景仍需补充真实原图测试。
