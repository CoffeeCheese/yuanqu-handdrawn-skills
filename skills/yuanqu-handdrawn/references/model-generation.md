# 会话内置图像生成

仅在本轮要生成或修改图片时读取。当前模型负责理解与指令，内置图像工具负责像素生成；二者能力分开描述。仅重构 skill 或分析规则时无需调用工具。

## 视觉输入与调用

使用当前会话实际提供的工具与参数。对于 `image_gen`：

- 在调用前查看尚未看过的本地原图与风格参考。所有输入都有本地路径时，通过 `referenced_image_paths` 同时传入它们，按顺序在提示词中声明原图和风格参考。
- 有输入仅在会话中时，使用足以包含全部目标图的最小 `num_last_images_to_include`（最多 5），明确各图角色。两个输入机制互斥；无法包含必要图片时请用户重新附上缺少的图片。
- 指令明确要求一张 1:1 纯插画、完整成品、白纸背景；`transparent_background: false`。尺寸要求放在提示词中，只发送工具支持的字段。
- 提供原图进行风格转换属于编辑。针对性修正时，以已生成成品为编辑目标，并继续提供可用的原图与风格参考，重复主体保留项；所需输入仍按上述机制选择。
- 工具运行可能较久，按当前工具约定等待，不在调用尚未完成时重复生成。结果用当前环境提供的图像展示方式返回，避免输出整段 base64。

生成后以工具真实返回的文件路径为准，按 [output-layout.md](output-layout.md) 将选中的成品复制到输出根的 `images/`，生成记录保存到 `records/`。不能假设工具支持目标路径参数或承诺特定图像模型。若工具只返回内联图片、当前环境无法落盘，交付图片并明确说明文件尚未保存。

## 组织生成指令

将本次识别结果与 SKILL.md 的风格要求合并为一份简洁指令。下列结构用于说明输入角色，不是必须填写的表单：

```text
用途：风格转换。只生成一张完成的 1:1 正方形纯插画。
图1是主体身份、姿势、朝向、人数、遮挡和场景内容的唯一来源。
图2是选定的认可风格成品，仅借鉴圆润造型、实心竖胶囊眼、灰蓝蜜桃配色、
造型夸张尺度、色块组织、分区颜料质感与自然边缘。
图1决定发型、配件、头向、动作、遮挡与背景线索；人物头身观感向图2靠近。

本张必须保留：[依据原图填写可见特征与真实遮挡]。
构图：[依据原图、用户用途和必要动作填写；原有身份场景线索按需保留为浅色背景组]。
风格：[采用 style-calibration.md 的风格段，并用图2实际画法调整；区分脸部与衣发材质]。
```

参考图已能表达的笔触交给视觉输入。避免用固定脸型比、眼距、坐标、发块数量或 SVG 语法覆盖模型的视觉判断。用户需要系列插画时，沿用同一套参考和核心要求，同类主体固定参考选择，按每张原图替换保留项。不要额外写“全图均匀颗粒”“所有阴影都很淡”或直接删除旗帜等场景线索，覆盖已经观察到的参考画法。

## 核对与记录

分别记录主体与风格核对结果。可用“通过／有偏差／未核对”，有偏差时说明具体可见问题；未查看成品时不得记为通过。对外部 API 调用、指定模型或逐像素复现不作隐含承诺。

保存生成指令与实际输出信息，不编造 scene、seed 或引擎报告。历史代码样张只证明旧绘图模块的表现，不能证明当前模型生成的质量。未进行本轮真实成图测试时，说明规则已校验、图像效果尚待验证。
