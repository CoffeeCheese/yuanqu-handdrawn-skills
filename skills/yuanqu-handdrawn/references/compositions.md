# 五类构图

本文件只用于 V1 固定几何；模型生成与 Canvas V3 的构图按 SKILL.md 和实际风格参考决定。

依据原图选择分支，不按文件名或参考人物选择。保留主要对象数量和相对关系，无法判断目标主体才询问。

## portrait — 人物肖像

保留发型轮廓、最多三项识别特征、头向与遮挡。大头短肩，裁减身体，完整保留发型/帽子。手和道具仅在姿势、遮挡或身份必需时保留，背景为空。单头最终基准高度至少 260/1000，多头每个至少 150/1000。

语法样例：[examples/portrait.json](examples/portrait.json)。

## anime — 人形动漫

采用肖像构图，大胆替换原有五官。尖发合并钝化，保留轮廓、分缝与关键呆毛。闭眼、眼罩、墨镜、发遮眼与背影保留，不根据角色常见形象补全隐藏内容。

语法样例：[examples/anime.json](examples/anime.json)，演示一闭一睁，不是角色身份模板。

## object — 物品

保留轮廓、关键比例、必要构件与遮挡，简化微小装饰和背景。完整主体在白纸中央。`heads=[]`、`bodies=[]`、`source.people=0`；不添加脸或拟人化。自行车要保留两轮与车架、车把、座位的连接关系；结构优先于强行压成不连通块。

语法样例：[examples/object.json](examples/object.json)。

## travel — 有人的旅游照

保留主要旅行者的相对位置、互动、头向与遮挡，头大身小，每头最终基准高度至少 95/1000。原图中一个主要地标用 2–5 块浅形表示，`source.landmark` 写真实线索，背景透明度不超过 0.32。删无关人群、文字、杂物与次要地标，背影保持背影。

语法样例：[examples/travel.json](examples/travel.json)，演示正脸/背影组合，尚非用户原图实测。

## landscape — 无人风景

3–7 个浅色圆润块面保留一个可辨地标或空间结构。使用 `background`，`objects=[]`、`heads=[]`、`bodies=[]`、`source.people=0`。不加入人物或五官。

语法样例：[examples/landscape.json](examples/landscape.json)。

## 图层与互动

全局：背景 → 身体 → 物品 → 按数组由后到前的头。头内：后发 → 可见耳 → 面罩 → 眼/腮红 → 前发 → 配件。

遮脸的手/道具放该头的局部 `prop`/`occluder` 配件，全局 `objects` 不能覆盖脸。跨人物遮挡用头顺序和局部配件表达；这一层级不能保持重要互动时记录限制，修正一次仍不成立就标失败，不改原图姿势。
