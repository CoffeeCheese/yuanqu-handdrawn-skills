# 圆趣手绘

将用户原图转换为一张完成的 1:1 正方形手绘插画。当前模型负责识别、构图与生成指令，会话内置图像生成负责成图；以风格接近参考成品、主体可辨和姿态保留为目标。

## 输入与参考

用户只需提供原图；风格参考与输出目录可选。缺少原图或主体选择有实质歧义时追问，其余情况直接执行。多图或目录按用户指定范围处理；目录默认只处理直属图片，排除本轮输出。

- **原图**是身份、主体数量、发型、服装、朝向、姿势、真实遮挡与场景内容的唯一来源。识别以实际可见内容为准，看不清的隐藏特征保持隐藏。
- **风格参考**采用用户指定的成品；未提供时查看随包的 [assets/handdrawn-reference.jpg](assets/handdrawn-reference.jpg)。仅借鉴造型、配色、笔触和完成度，主体、姿势与配件来自原图。参考图本身的身份或遮挡错误不成为生成要求。
- `<skill-root>` 是当前加载的 `SKILL.md` 所在目录，所有随包资源从这里定位。查看本地图片后再使用；将原图和风格参考都作为视觉输入传入生成工具，并清楚标记角色。

## 风格要求

以温柔的灰蓝、蜜桃橘和白纸留白为主。使用柔和圆脸、醒目的深灰蓝实心竖胶囊眼、少量淡腮红和顺着发型走势的连续发块。人形脸部省略鼻嘴、眉睫与写实眼细节；眼睛数量、闭眼和遮挡遵循原图，侧脸保持侧脸，背影保持背影。必要配件承担识别特征。

表现蜡笔／彩铅的颜料颗粒、断续笔触和自然边缘。头发、衣服与必要背景可以有可读的层次和纹理，脸部留白与眼睛保持干净。灰蓝与蜜桃的深浅可变化，必要识别配件可用少量低饱和辅助色。

让模型根据原图和风格参考决定脸型、眼睛比例、发块、衣纹、留白和构图。舒适地容纳完整头发或帽子；坐姿、双手、衣领或座椅对识别与动作有帮助时保留。头像需求采用头肩构图；旅游照保留主要旅行者、互动和一个浅色场景线索；无人风景或物品只转换原有内容，保持无拟人化。

成品是纯插画，无新增人物、道具、文字、标签或水印。用户本轮风格与构图要求优先。

## 生成与核对

1. 查看原图和风格参考，提炼本张必须保留的轮廓、姿势、眼耳遮挡与识别特征。直接形成生成指令，无需先拟合坐标、scene JSON 或 SVG。
2. 使用当前会话的内置图像生成能力。若可用的是 `image_gen`，阅读 [references/model-generation.md](references/model-generation.md) 的调用约定；不配置外部 API、密钥或另选模型。只分析／只写提示词的请求停在指令交付。
3. 每张先生成一份候选，再查看成品并分别核对：原图保留项是否正确；是否呈现参考的配色、圆润造型、胶囊眼、笔触与白纸感。风格审核以实际参考成品为准，不以几何比例或脚本通过代替。
4. 有具体可修正偏差时，最多进行一次针对性修改，再核对。第二次仍有偏差就如实记录并交付；批量继续下一张。用户要求继续修改时可进行新一轮。

内置图像生成不可用或失败时，说明本次未完成成图，提供可用的生成指令。代码绘图只在用户明确选择时启用；不能悄悄替换为代码近似图或外部 API。

## 保存与交付

用户指定目录优先，否则使用当前工作目录的 `output/yuanqu-handdrawn/`。每张只交付一张选中的成品，以 `<原图名>-yuanqu.png` 命名，重名编号；用户指定 JPG 时转换格式。正方形是画幅要求，默认请求 1024×1024，保存时记录实际像素尺寸，不能把请求值当作已实现。

保存图片与同名 `.generation.md`：记录原图和风格参考路径、实际生成指令、使用的能力、工具真实提供的参数、尝试次数、最终核对结果及具体偏差。仅记录工具明确返回的模型标识；无法得知时写未知，不猜测模型、种子或隐藏参数。展示成品并给出保存路径。

稳定性来自持续使用同一风格参考、核心要求和核对方法。生成结果可能变化，已保存的成品是复用依据；记录指令有助于迭代，不保证重新生成逐像素一致。

## 明确选择代码绘图时

用户要求本地代码或离线绘图时，读取 [references/code-handdrawn.md](references/code-handdrawn.md)。只有明确要求固定几何复现时才读取 [references/legacy-geometry.md](references/legacy-geometry.md)。这些旧绘图模块的比例、配色表、数据格式与渲染依赖仅适用于其自身，不进入默认模型生成流程。

本技能是原创融合风格实验，不是官方 Grok 素材。
